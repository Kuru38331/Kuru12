Kuru12 รุ่นแอปหน้าต่างจริง

เมื่อ GitHub สร้าง Release สำเร็จ ให้ดาวน์โหลด ZIP ทั้งชุด แตกไฟล์ แล้วเปิด Kuru12.exe
ไม่ต้องติดตั้ง Python แยก ไม่ต้องเปิดเบราว์เซอร์
ตรวจอัปเดตใหม่จาก Kuru38331/Kuru12 ตอนเปิดแอป
ยังต้องทดสอบแพ็กเกจ Windows จริงหลัง GitHub สร้างเสร็จ

HSHO Friends Launcher — 2026.10.23.2

1. แตก ZIP ทั้งหมดไว้ในโฟลเดอร์ใหม่ ห้ามเปิดจากใน ZIP
2. เปิด Steam บัญชีของแต่ละคน
3. ดับเบิลคลิก Open-HSHO.cmd แอปจะเปิดในเบราว์เซอร์ของเครื่อง
4. ใส่โฟลเดอร์เกมที่มี HSHO.exe แล้วกดเล่น
5. คงหน้าต่าง Launcher/ตัวรันไว้ระหว่างเล่น ออกจากเกมก่อนกดปิด Launcher

เครื่องที่มี Python 3.10+ ใช้ตัวที่ติดตั้งอยู่ได้
ถ้าไม่มี จะเตรียม Python embeddable 3.13.7 จาก python.org ครั้งแรก
ต้องมีอินเทอร์เน็ต และตรวจลายเซ็น Python ก่อนใช้ ไม่แก้ PATH หรือขอสิทธิ์แอดมิน
ยังไม่ได้ทดสอบขั้นตอนเตรียม runtime นี้บน Windows จริง

รุ่นนี้ติดตั้งแพตช์ที่รวมอยู่ในโฟลเดอร์อัตโนมัติก่อนเปิดเกม
ยังไม่มีเซิร์ฟเวอร์เผยแพร่อัปเดต จึงยังไม่ดาวน์โหลดรุ่นใหม่เอง

แก้รหัส local profile ที่เคยเป็น local-test-player ซ้ำกันทุกเครื่อง
รหัสใหม่แยกตามบัญชี Steam ที่ active ในเครื่อง เป็นรหัส local เท่านั้น ไม่ใช่การยืนยัน Steam
ยังไม่ยืนยันว่าแก้ทุกสาเหตุของการเข้าห้องไม่ได้ ต้องทดสอบเพื่อนจริงหลายเครื่อง
ทุกคนปิดเกมและ Launcher รุ่นเก่า อัปเดตรุ่นเดียวกัน แล้วสร้างห้องใหม่ก่อนลอง

หากคนใดเข้าห้องไม่ได้ โฮสต์และคนนั้นกดส่งรายงานปัญหา จะดาวน์โหลด HSHO-Friend-Report.zip
ส่งทั้งสอง ZIP กลับในแชต พร้อมบอกว่าขึ้นตอนเข้าห้องหรือเริ่มแมตช์
รายงานไม่รวมตั๋ว Steam, session token, ชื่อบัญชี หรือเนื้อหาคำขอเกม

ไฟล์เกมเต็ม, Steam และ runtime ของเกมไม่รวมในชุดนี้
เพื่อนต้องมีไฟล์เกม build เดียวกันอยู่แล้ว

เซฟผู้เล่นแยกบัญชีเก็บที่ %LOCALAPPDATA%\HSHO-Launcher\profiles\local-...\local-character-state.json
ไม่อ่านเซฟรวมจากโฟลเดอร์ Launcher อัตโนมัติ
ต้องการเซฟเดิม ให้เปิด Steam บัญชีของคุณแล้วกด นำเข้าเซฟเก่าของฉัน เลือก server/local-character-state.json เดิม
ไม่เขียนทับเซฟที่มีอยู่แล้ว และไม่ลบต้นฉบับ
ข้อมูลแยกปัจจุบันคือการเลือกตัวละคร สกิน เปิร์ก เครื่องราง/คำสาป และชุดไอเท็มที่บันทึกไว้
คลังของที่เปิดให้ทดสอบยังเป็นรายการเดียวกันทุกคน ระบบเลเวล/เงิน/ประวัติแมตช์ยังไม่ครบ และยังไม่มีคลาวด์เซฟข้ามเครื่อง
