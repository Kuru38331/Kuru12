วิธีเปิดบอทบน Windows

1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org ถ้ายังไม่มี
2. แตก ZIP ทั้งหมดลงโฟลเดอร์ก่อน
3. ดับเบิลคลิก START-BOT.bat จะติดตั้งไลบรารีให้อัตโนมัติ
4. วาง Discord Bot Token แล้วกด Enter (ข้อความจะไม่แสดงเพื่อป้องกันคนอื่นเห็น)
5. ใส่ Server ID เพื่อทดสอบคำสั่งได้เร็ว หรือกด Enter ข้าม
6. เปิด Discord ใช้ /daily /banner /collection /team และ /battle

ต้องสร้างบอทที่ Discord Developer Portal และเชิญเข้าเซิร์ฟเวอร์ก่อน
เลือก OAuth2 scopes: bot และ applications.commands
สิทธิ์ที่ใช้: View Channels, Send Messages, Embed Links และ Attach Files
ไม่ต้องเปิด Message Content Intent

Token จะไม่ถูกบันทึกลงไฟล์ ต้องใส่ใหม่เมื่อเปิดบอท
ห้ามส่ง Token ให้คนอื่น หากรั่วให้กด Reset Token ใน Developer Portal
เก็บหน้าต่างนี้ไว้ระหว่างใช้งาน ปิดหน้าต่างแล้วบอทจะออฟไลน์
ข้อมูลผู้เล่นอยู่ใน gacha.sqlite3 อย่าลบถ้าต้องการเก็บข้อมูลเดิม
รันบอทเพียงหน้าต่างเดียว คำท้าและแมตช์จะหายเมื่อรีสตาร์ต

คู่มือเพิ่มเติม: README.md

รุ่น UI ใหม่: /banner เปิดตู้กาชา กดปุ่มสุ่ม 1/10 ครั้ง ดูการันตีเป็นการส่วนตัว
หน้าต่อสู้แสดง HP/MP สกิลและประวัติเทิร์น ต้องเก็บโฟลเดอร์ assets ไว้กับ bot.py

เพิ่ม Kuru 5 ดาว Limited ธาตุมืด อาวุธผีเสื้อ สเกล HP และสตั้น
/banner เปิดตู้ Kuru /character ดูสกิล เลือกตู้ถาวรได้ในตัวเลือกคำสั่ง /banner
ยังไม่กำหนดวันปิดตู้ ตัวนับการันตีแยกจากตู้ถาวร เก็บไฟล์ฐานข้อมูลเดิมไว้

Kuru มีอันติแล้ว: สุริยคราสพันผีเสื้อ ดาเมจ 60% HP สูงสุด
ชาร์จพลังให้ครบ 100 แล้วกดปุ่มอันติในเทิร์นตัวเอง ไม่ใช้ MP

รุ่นใหม่ 4v4:
เพิ่ม Eiji 5 ดาวถาวร/หลุดเรท, Yuko Hanaka 5 ดาว Limited ตู้แยก, Mala Natsumi 4 ดาวพูลร่วม
ตู้ Limited ใช้ 50/50 ถ้าหลุดเป็น Eiji ครั้งถัดไปที่ได้ 5 ดาวจะเป็นตัวประจำตู้นั้นแน่นอน
ใช้ /squad เลือกตัวละครที่มี 4 ตัวไม่ซ้ำ เช่น Kuru, Eiji, Yuko Hanaka, Mala Natsumi
แล้ว /battle เลือก mode 4v4 ผู้เล่น 2 คนควบคุมทีมคนละ 4 ตัว เลือกเป้าหมายได้
คู่แข่งต้องมีทีมที่จัดไว้ด้วย /squad ก่อน โหมด 1v1 ยังเล่นได้เหมือนเดิม
