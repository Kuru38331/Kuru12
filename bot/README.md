# บอท Discord กาชา + PvP

Python 3.10+ ใช้ discord.py และ SQLite เริ่มต้น 1,000 เพชร พร้อมอัศวิน 1 ตัว

## ติดตั้งและเริ่ม

```sh
cd /workspace/discord-gacha
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

กำหนด `DISCORD_BOT_TOKEN` เป็นตัวแปรสภาพแวดล้อมอย่างปลอดภัยก่อนรัน ห้ามใส่ token ในโค้ดหรือส่งในแชต บอทไม่อ่านไฟล์ .env อัตโนมัติ

1. สร้าง Application และ Bot ใน Discord Developer Portal
2. คัดลอก Bot Token ไปใส่ใน secret ของเครื่องที่รัน
3. ติดตั้งบอทเข้าเซิร์ฟเวอร์ด้วย OAuth2 scopes `bot` และ `applications.commands` พร้อมสิทธิ์ View Channels, Send Messages, Embed Links และ Attach Files ไม่ต้องให้ Administrator หรือเปิด Message Content Intent
4. ตั้ง `DISCORD_GUILD_ID` เป็น ID เซิร์ฟเวอร์ทดสอบเพื่อให้คำสั่งปรากฏเร็ว หากไม่ตั้ง จะลงทะเบียนคำสั่งแบบ global ซึ่งอาจใช้เวลาเผยแพร่ หลีกเลี่ยงการสลับโหมดบ่อยเพราะคำสั่งเดิมอาจยังค้างใน Discord
5. รัน `bot.py` แล้วใช้ `/collection`, `/daily`, `/banner`, `/team`, `/battle`

`GACHA_DB` เลือกตำแหน่งฐานข้อมูลได้ ค่าเริ่มต้นคือ gacha.sqlite3 ข้าง bot.py สำรองฐานข้อมูลและรันเพียง 1 process ต่อฐานข้อมูล

## กติกา

- สุ่มครั้งละ 100 เพชร: 3★ 88%, 4★ 10%, 5★ 2% การันตี 5★ ภายใน 50 ครั้งและรีเซ็ตเมื่อได้ 5★
- ตัวละครซ้ำเก็บเป็นจำนวนสะสม ยังไม่มีระบบอัปเกรดหรือขาย
- `/daily` รับ 300 เพชร รีเซ็ต 00:00 UTC หรือ 07:00 เวลาไทย
- `/banner` หรือ `/gacha` เปิดตู้พร้อมแบนเนอร์และปุ่มสุ่ม 1 ครั้ง / 10 ครั้ง / ดูการันตี ไม่หักเพชรจนกว่าจะกดสุ่ม
- สุ่ม 10 ครั้งใช้ 1,000 เพชร หักเพชรและบันทึกผลทั้งชุดใน transaction เดียว
- การันตี 4★ ขึ้นไปภายใน 10 ครั้ง นับต่อเนื่องทั้งสุ่มเดี่ยวและสุ่มสิบ รีเซ็ตเมื่อได้ 4★ หรือ 5★ อัตราที่ระบุเป็นอัตราพื้นฐานก่อนการันตี
- `/team` เลือกตัวละครที่เป็นเจ้าของสำหรับ PvP แบบ 1 ต่อ 1
- `/battle opponent:@เพื่อน` ต้องให้อีกฝ่ายรับคำท้า แล้วสุ่มผู้เริ่มก่อน
- สนามแบบ Embed แสดง HP/MP, ธีมธาตุ, เทิร์นปัจจุบัน และประวัติ 3 การกระทำล่าสุด ชื่อสกิลเปลี่ยนตามตัวละคร แต่ทุกตัวใช้กติกาสกิลเดียวกัน
- เริ่มด้วย 100 MP สกิลแรง 2 เท่าใช้ 20 MP และต้องเว้น 2 เทิร์นของตน โจมตีปกติฟื้น 10 MP ป้องกันลดดาเมจครั้งถัดไปครึ่งหนึ่งและฟื้น 15 MP ยอมแพ้ได้ในเทิร์นของตน
- ผู้เล่นมีได้ครั้งละ 1 คำท้าหรือแมตช์ หมดเวลาเมื่อไม่มีการกดปุ่มของผู้ร่วมแมตช์ 120 วินาที ครบ 100 เทิร์นเสมอ
- PvP ยังไม่มีรางวัลหรืออันดับ และค่าสถานะยังต้องปรับสมดุลจากการเล่นจริง

ข้อมูลผู้เล่น เพชร ตัวละคร และตัวที่เลือกคงอยู่หลังรีสตาร์ต ส่วนคำท้าและแมตช์เก็บในหน่วยความจำและยกเลิกเมื่อรีสตาร์ต ปุ่มแมตช์เก่าจะใช้ต่อไม่ได้

## สถานะการตรวจสอบ

มีการทดสอบระบบเกมและ SQLite แบบออฟไลน์ การเชื่อมต่อ Discord จริงต้องใช้ Bot Token และเซิร์ฟเวอร์ที่ติดตั้งบอท จากนั้นควรทดสอบรับ/ปฏิเสธคำท้า สิทธิ์การกดปุ่ม ลำดับเทิร์น และหมดเวลา ด้วยบัญชีผู้เล่นสองคน

## แก้ 403 Missing Access (50001)

ข้อผิดพลาดนี้เกิดตอนลงทะเบียนคำสั่งในเซิร์ฟเวอร์ ไม่ได้แปลว่า Bot Token ผิด ตรวจว่า Server ID เป็น ID ของเซิร์ฟเวอร์ที่เชิญบอทตัวเดียวกันนี้แล้ว ไม่ใช่ Channel ID หรือ User ID และเชิญด้วย scopes `bot` และ `applications.commands` รุ่นนี้จะลองลงทะเบียนแบบ global แทนเมื่อเข้าเซิร์ฟเวอร์ที่ระบุไม่ได้ พร้อมพิมพ์ลิงก์เชิญบอทหลังเชื่อมต่อสำเร็จ คำสั่ง global อาจใช้เวลาปรากฏ และยังต้องเชิญบอทเข้าเซิร์ฟเวอร์ก่อนใช้งาน

ถ้าไม่ทราบ Server ID กด Enter ข้ามตอนเปิดบอทได้ หากตั้ง `DISCORD_GUILD_ID` ไว้ในระบบ ต้องล้างหรือแก้ค่าตัวแปรนั้นด้วย

ตัวละคร: อัศวิน/จอมเวท/นักธนู 3★, พาลาดิน 4★, ราชามังกร 5★ ข้อมูลตัวละคร เพชร และจำนวนสุ่มการันตีจากรุ่นเดิมใช้ต่อได้โดยไม่ต้องลบฐานข้อมูล

## อัปเดตรุ่น UI

ปิดบอทก่อน แตก ZIP ลงโฟลเดอร์ใหม่ แล้วคัดลอก `gacha.sqlite3` เดิมมาต่อได้ ระบบเพิ่มคอลัมน์การันตี 4★ อัตโนมัติและเก็บเพชร/ตัวละคร/การันตี 5★ เดิมไว้ โดยตัวนับ 4★ ใหม่เริ่มที่ 0 เก็บโฟลเดอร์ `assets` และไฟล์ `presentation.py` มาด้วย เปิด START-BOT.bat แล้วใช้ `/banner` หากไม่มีรูปหรือการ์ดให้ตรวจสิทธิ์ Embed Links และ Attach Files ในห้องนั้น

Discord เป็นผู้กำหนดรูปทรงและสีปุ่ม มุมโค้ง ฟอนต์ และตำแหน่งการ์ดอาจต่างกันระหว่างมือถือกับเดสก์ท็อป ไม่มีการกำหนด CSS บนข้อความบอท

## Kuru 5★ Limited · มืด

- บทบาท HP-scaling / Stun DPS อาวุธ: ผีเสื้อแห่งราตรี
- HP 240, MP 100 โจมตีปกติ “ปีกเงา” สร้างดาเมจ 16% ของ HP สูงสุด (เริ่มต้น 38) และฟื้น 10 MP
- สกิล “ราตรีผีเสื้อ” สร้างดาเมจ 32% ของ HP สูงสุด (เริ่มต้น 76) ใช้ 30 MP และสตั้นเป้าหมายข้าม 1 เทิร์นอัตโนมัติ เว้น 3 เทิร์นที่ลงมือได้ก่อนใช้ซ้ำ ค่าสเกลปัดเศษลง การป้องกันลดดาเมจแต่ไม่กันสตั้น และไม่มีสตั้นเมื่อเป้าหมายแพ้แล้ว
- สเกลใช้ HP สูงสุดขณะต่อสู้ ไม่ใช่ HP ที่เหลือหรือ ATK
- `/banner` และ `/gacha` เปิดตู้ Kuru เป็นค่าเริ่มต้น เลือก `/banner banner:ตู้ถาวร` เพื่อเปิดตู้เดิม
- ตู้ Kuru มี 5★ 2%, 4★ 10%, 3★ 88% ก่อนการันตี 5★ ที่ออกจากตู้นี้เป็น Kuru 100% ไม่มี 50/50 และการันตีภายใน 50 ครั้ง การันตี 4★ ขึ้นไปภายใน 10 ครั้ง
- Kuru ไม่อยู่ในพูลตู้ถาวร ตัวนับการันตีทั้งสองระดับแยกกันระหว่างตู้ ใช้เพชรกระเป๋าเดียวกัน การันตีตู้ถาวรเดิมยังอยู่ครบ
- คำว่า Limited หมายถึงตัวละครเฉพาะตู้นี้ ตอนนี้ยังไม่ได้กำหนดวันสิ้นสุด ผู้ดูแลปิดตู้ได้ด้วย `KURU_BANNER_OPEN=false` แล้วรีสตาร์ตบอท ผู้ที่เป็นเจ้าของ Kuru แล้วยังจัดทีมและต่อสู้ได้ตามปกติ บัญชีและตัวนับการันตีไม่ถูกลบ
- `/character character:Kuru` ดูค่าสถานะ อาวุธ และสูตรสกิลได้โดยไม่ต้องเป็นเจ้าของ

ค่าสถานะเป็นชุดเริ่มต้น ยังต้องปรับสมดุลจากการประลองจริง อาร์ตแบนเนอร์เป็นตราผีเสื้อ ไม่ใช่ภาพตัวละครฉบับสมบูรณ์

## อันติ Kuru · สุริยคราสพันผีเสื้อ

- ดาเมจ 60% ของ HP สูงสุด (เริ่มต้น 144) ใช้พลังอันติ 100 ไม่ใช้ MP และใช้ได้เฉพาะเทิร์นตัวเอง
- ไม่มีสตั้นเพิ่มเติม การป้องกันลดดาเมจอันติครึ่งหนึ่งได้ อันติแยกจากคูลดาวน์สกิล จึงใช้ได้แม้สกิลยังคูลดาวน์
- เริ่มทุกแมตช์ที่พลัง 0/100 โจมตีปกติ +25 ใช้สกิล +35 ป้องกัน +15 และเมื่อถูกโจมตีจนเสีย HP +10 พลังสูงสุด 100

- ปุ่มอันติแยกอยู่ในหน้าต่อสู้ เปลี่ยนเป็นสีแดงเมื่อพร้อมใช้ เกจจะปรากฏบนการ์ด Kuru ขณะนี้อันติมีเฉพาะ Kuru ตัวละครอื่นปุ่มจะปิดไว้
- พลังอันติอยู่ในแมตช์เท่านั้น ไม่ค้างข้ามการต่อสู้ ไม่มีการเปลี่ยนฐานข้อมูลผู้เล่น
