# บอท Discord กาชา + PvP

Python 3.10+ ใช้ discord.py และ SQLite เริ่มต้น 1,000 เพชร พร้อมอัศวิน 1 ตัว

## ติดตั้งและเริ่ม

```sh
cd /workspace/discord-gacha
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

กำหนด `DISCORD_BOT_TOKEN` เป็นตัวแปรสภาพแวดล้อมอย่างปลอดภัยก่อนรัน ห้ามใส่ token ในโค้ดหรือส่งในแชต บอทไม่อ่านไฟล์ .env อัตโนมัติ

1. สร้าง Application และ Bot ใน Discord Developer Portal
2. คัดลอก Bot Token ไปใส่ใน secret ของเครื่องที่รัน
3. ติดตั้งบอทเข้าเซิร์ฟเวอร์ด้วย OAuth2 scopes `bot` และ `applications.commands` พร้อมสิทธิ์ View Channels และ Send Messages ไม่ต้องให้ Administrator หรือเปิด Message Content Intent
4. ตั้ง `DISCORD_GUILD_ID` เป็น ID เซิร์ฟเวอร์ทดสอบเพื่อให้คำสั่งปรากฏเร็ว หากไม่ตั้ง จะลงทะเบียนคำสั่งแบบ global ซึ่งอาจใช้เวลาเผยแพร่ หลีกเลี่ยงการสลับโหมดบ่อยเพราะคำสั่งเดิมอาจยังค้างใน Discord
5. รัน `bot.py` แล้วใช้ `/collection`, `/daily`, `/gacha`, `/team`, `/battle`

`GACHA_DB` เลือกตำแหน่งฐานข้อมูลได้ ค่าเริ่มต้นคือ gacha.sqlite3 ข้าง bot.py สำรองฐานข้อมูลและรันเพียง 1 process ต่อฐานข้อมูล

## กติกา

- สุ่มครั้งละ 100 เพชร: N 60%, R 28%, SR 10%, SSR 2% การันตี SSR ภายใน 50 ครั้งและรีเซ็ตเมื่อได้ SSR
- ตัวละครซ้ำเก็บเป็นจำนวนสะสม ยังไม่มีระบบอัปเกรดหรือขาย
- `/daily` รับ 300 เพชร รีเซ็ต 00:00 UTC หรือ 07:00 เวลาไทย
- `/team` เลือกตัวละครที่เป็นเจ้าของสำหรับ PvP แบบ 1 ต่อ 1
- `/battle opponent:@เพื่อน` ต้องให้อีกฝ่ายรับคำท้า แล้วสุ่มผู้เริ่มก่อน
- โจมตีปกติ, สกิลแรง 2 เท่าต้องเว้น 2 เทิร์นของตน, ป้องกันลดดาเมจครั้งถัดไปครึ่งหนึ่ง และยอมแพ้ในเทิร์นของตน
- ผู้เล่นมีได้ครั้งละ 1 คำท้าหรือแมตช์ หมดเวลาเมื่อไม่มีการกดปุ่มของผู้ร่วมแมตช์ 120 วินาที ครบ 100 เทิร์นเสมอ
- PvP ยังไม่มีรางวัลหรืออันดับ และค่าสถานะยังต้องปรับสมดุลจากการเล่นจริง

ข้อมูลผู้เล่น เพชร ตัวละคร และตัวที่เลือกคงอยู่หลังรีสตาร์ต ส่วนคำท้าและแมตช์เก็บในหน่วยความจำและยกเลิกเมื่อรีสตาร์ต ปุ่มแมตช์เก่าจะใช้ต่อไม่ได้

## สถานะการตรวจสอบ

มีการทดสอบระบบเกมและ SQLite แบบออฟไลน์ การเชื่อมต่อ Discord จริงต้องใช้ Bot Token และเซิร์ฟเวอร์ที่ติดตั้งบอท จากนั้นควรทดสอบรับ/ปฏิเสธคำท้า สิทธิ์การกดปุ่ม ลำดับเทิร์น และหมดเวลา ด้วยบัญชีผู้เล่นสองคน

## แก้ 403 Missing Access (50001)

ข้อผิดพลาดนี้เกิดตอนลงทะเบียนคำสั่งในเซิร์ฟเวอร์ ไม่ได้แปลว่า Bot Token ผิด ตรวจว่า Server ID เป็น ID ของเซิร์ฟเวอร์ที่เชิญบอทตัวเดียวกันนี้แล้ว ไม่ใช่ Channel ID หรือ User ID และเชิญด้วย scopes `bot` และ `applications.commands` รุ่นนี้จะลองลงทะเบียนแบบ global แทนเมื่อเข้าเซิร์ฟเวอร์ที่ระบุไม่ได้ พร้อมพิมพ์ลิงก์เชิญบอทหลังเชื่อมต่อสำเร็จ คำสั่ง global อาจใช้เวลาปรากฏ และยังต้องเชิญบอทเข้าเซิร์ฟเวอร์ก่อนใช้งาน

ถ้าไม่ทราบ Server ID กด Enter ข้ามตอนเปิดบอทได้ หากตั้ง `DISCORD_GUILD_ID` ไว้ในระบบ ต้องล้างหรือแก้ค่าตัวแปรนั้นด้วย
