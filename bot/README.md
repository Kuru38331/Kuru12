# ASTRAL · Discord Gacha & Arena

บอทกาชา 3★/4★/5★ และ PvP 1v1 / 4v4 ด้วย Python 3.10+, discord.py และ SQLite

## เปิดบอทบน Windows

แตก ZIP ลงโฟลเดอร์ใหม่ แล้วเปิด `START-BOT.bat` ต้องติดตั้ง Python ก่อน สคริปต์จะสร้าง .venv และติดตั้งไลบรารีให้ ใส่ Bot Token ที่พรอมป์ต์แบบซ่อนข้อความ ห้ามส่ง Token ในแชตหรือใส่ลงโค้ด

สร้าง Bot ใน Discord Developer Portal แล้วเชิญด้วย scopes `bot` และ `applications.commands` พร้อมสิทธิ์ View Channels, Send Messages, Embed Links, Attach Files ไม่ต้องเปิด Message Content Intent หรือให้ Administrator

กรอก Server ID ที่บอทอยู่เพื่อให้คำสั่งปรากฏเร็ว หรือ Enter ข้ามเพื่อลงทะเบียน global หาก Discord ตอบ Missing Access (50001) บอทจะลองลงทะเบียน global แทน และแสดงลิงก์เชิญบอทหลังออนไลน์ คำสั่ง global อาจใช้เวลาเผยแพร่

ตัวแปรที่รองรับ: `DISCORD_BOT_TOKEN`, `DISCORD_GUILD_ID`, `GACHA_DB` (ค่าเริ่มต้น gacha.sqlite3 ข้าง bot.py) ตัวโปรแกรมไม่อ่าน .env อัตโนมัติ

## คำสั่ง

- `/daily`: รับ 300 เพชร รีเซ็ต 07:00 เวลาไทย เริ่มบัญชีด้วย 1,000 เพชรและอัศวินหนึ่งตัว
- `/banner`: เลือกตู้ Kuru Limited, Yuko Hanaka Limited หรือตู้ถาวร ค่าเริ่มต้น Kuru; `/gacha` เปิดตู้ Kuru เช่นกัน
- ปุ่มกาชา: สุ่ม 1 ครั้ง 100 เพชร / 10 ครั้ง 1,000 เพชร / ดูการันตี ผลและยอดเงินเห็นเฉพาะผู้กด ทุกคนใช้ตู้เดียวกันได้แต่คิดเงินและให้รางวัลแยกบัญชี
- `/collection`: ดูตัวละครและจำนวนสำเนา ตัวซ้ำยังไม่มีระบบอัปเกรด
- `/character`: เลือกดูอาวุธ สูตรสกิล และอันติได้ทุกตัวโดยไม่ต้องเป็นเจ้าของ
- `/team`: เลือกตัวละครที่เป็นเจ้าของลงสนาม 1v1
- `/squad`: กรอก slot1–slot4 เพื่อบันทึกทีม 4v4 หรือไม่กรอกเพื่อดูทีม ต้องเป็นตัวละครที่เป็นเจ้าของครบสี่ตัวและไม่ซ้ำกัน แยกจากตัวที่เลือก 1v1
- `/battle opponent:เพื่อน mode:1v1` หรือ `mode:4v4`: ฝ่ายถูกท้าต้องรับคำท้า ผู้เล่นมีคำท้าหรือแมตช์ได้ครั้งละหนึ่งรายการทั้งสองโหมด

ทีมที่เล่นร่วมกันได้: **Kuru + Eiji + Yuko Hanaka + Mala Natsumi** ต้องสุ่มให้ได้และเป็นเจ้าของก่อน ใช้ `/squad` เลือกทั้งสี่ตัว แล้วให้คู่แข่งจัดทีมของตนก่อนท้า

## ตู้และการหลุดเรท

อัตราพื้นฐาน: 5★ 2%, 4★ 10%, 3★ 88% ก่อนเงื่อนไขการันตี สุ่ม 5★ ภายใน 50 ครั้ง และ 4★ ขึ้นไปภายใน 10 ครั้ง นับรวมสุ่มเดี่ยวและสิบ ตัวนับรีเซ็ตเมื่อได้ระดับนั้นขึ้นไป

- ตู้ถาวร: 5★ ราชามังกร/Eiji, 4★ พาลาดิน/Mala Natsumi, 3★ อัศวิน/จอมเวท/นักธนู เลือกเท่ากันภายในระดับดาว
- Kuru Limited: เมื่อได้ 5★ มีโอกาส 50% เป็น Kuru และ 50% หลุดเป็น Eiji
- Yuko Hanaka Limited: เมื่อได้ 5★ มีโอกาส 50% เป็น Yuko และ 50% หลุดเป็น Eiji
- ถ้าหลุดเรท 5★ ครั้งถัดไปของตู้นั้นเป็นตัวประจำตู้แน่นอน หลังได้ตัวประจำตู้จะกลับไป 50/50 การันตีดาวและสถานะหลุดเรทแยกกันทุกตู้ ไม่แชร์ระหว่าง Kuru/Yuko/ถาวร แต่ใช้กระเป๋าเพชรเดียวกัน
- ไม่มี Kuru หรือ Yuko ในตู้ถาวร และไม่ข้ามตู้ Limited กัน 4★ ทั้งสองตัวอยู่ทุกตู้
- ยังไม่กำหนดวันปิดตู้ ผู้ดูแลปิดได้ด้วย `KURU_BANNER_OPEN=false` หรือ `YUKO_BANNER_OPEN=false` แล้วรีสตาร์ต ปิดตู้ไม่ลบตัวละครหรือการันตี
- อัปเดตจากรุ่นที่ Kuru เคยการันตีตัวประจำตู้ 100%: บัญชีที่มีตัวนับ Kuru บันทึกอยู่จะได้สถานะตัวประจำตู้แน่นอนสำหรับ 5★ ครั้งถัดไปหนึ่งครั้ง เพื่อรักษาสัญญาจากรุ่นเดิม หลังจากนั้นใช้ 50/50 ตามปกติ

## กติกาการต่อสู้

1v1 ใช้ตัวจาก `/team` ส่วน 4v4 มีผู้เล่นสองคน คนละสี่ตัวจาก `/squad` สุ่มฝ่ายเริ่มก่อน จากนั้นเดินคิวสลับช่องของทั้งสองทีม เช่น A1 → B1 → A2 → B2 ผู้เล่นควบคุมเฉพาะตัวที่ถึงคิว เลือกเป้าหมายผ่านเมนูใน 4v4 แล้วโจมตี/ใช้สกิล/อันติ ตัวที่ HP เป็นศูนย์จะถูกข้าม ชนะเมื่อทีมตรงข้ามล้มครบสี่ตัว ยอมแพ้คือแพ้ทั้งทีม

- โจมตี: ฟื้น 10 MP / ป้องกัน: ลดดาเมจครั้งถัดไป 50% และฟื้น 15 MP ไม่กันสตั้นหรือแผลฮิกังบาน
- อันติของ Kuru, Eiji, Yuko, Mala ใช้พลัง 100 ไม่ใช้ MP เริ่มแต่ละแมตช์ที่ 0 โจมตี +25, สกิล +35, ป้องกัน +15, เสีย HP +10 สูงสุด 100 หลังใช้อันติเหลือ 0 ไม่ได้พลังคืนจากการใช้อันติครั้งนั้น
- สตั้นข้ามเทิร์นของเป้าหมายหนึ่งครั้งอัตโนมัติ ไม่ลดคูลดาวน์สกิลในเทิร์นที่ถูกข้าม ใน 4v4 การสตั้นตัวหนึ่งไม่ข้ามทั้งทีม
- แผลฮิกังบานเริ่มทำงานเมื่อเป้าหมายถึงคิว ถ้าแผลทำให้ล้มจะข้ามคิวทันที การใส่แผลซ้ำเปลี่ยนระยะเวลาเป็นค่าจากท่าล่าสุด ไม่ซ้อนดาเมจหลายชั้น
- หมดเวลาเมื่อไม่มีการเล่น 120 วินาที สูงสุด 100 เทิร์นใน 1v1 / 200 ใน 4v4 แล้วเสมอ รวมเทิร์นที่ถูกสตั้นข้าม ไม่มีรางวัลหรือแรงก์ PvP ในรุ่นนี้
- เลือกทีมใหม่ไม่ได้ระหว่างมีคำท้าหรือกำลังต่อสู้ ค่าสถานะ HP/MP/พลัง/ภาพบันทึก/แผลเริ่มใหม่ทุกแมตช์

## อัปเดตและเก็บข้อมูล

ปิดบอทก่อนอัปเดต สำรอง gacha.sqlite3 แล้วแตก ZIP ลงโฟลเดอร์ใหม่และคัดลอกฐานข้อมูลเดิมไปไว้ข้าง bot.py โครงสร้างข้อมูลอัปเกรดอัตโนมัติ รักษาเพชร ตัวละคร ตัวนับ และทีมเดิม เก็บ `assets` และ `presentation.py` ไว้ด้วย

รันหนึ่ง process ต่อฐานข้อมูล คำท้าและแมตช์อยู่ในหน่วยความจำและยกเลิกเมื่อรีสตาร์ต ปุ่มเก่าจะใช้ต่อไม่ได้ เพชร/ตัวละคร/การันตี/ทีม 4v4 อยู่ใน SQLite และคงอยู่หลังรีสตาร์ต

## พัฒนาและทดสอบ

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python start.py
```

มีชุดทดสอบเกม ฐานข้อมูล การอัปเกรด save และ UI ผ่าน mock ของ Discord รวมการจำลองแข่ง 4v4 เต็มแมตช์ การแสดงผลและการเชื่อมต่อจริงยังต้องทดสอบด้วย Bot Token และผู้เล่นสองบัญชี Discord เป็นผู้กำหนดฟอนต์และรูปแบบปุ่ม อาร์ตปัจจุบันเป็นตราสัญลักษณ์แบนเนอร์ ยังไม่ใช่ภาพตัวละครฉบับสมบูรณ์
